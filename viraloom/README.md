# ViraLoom AI — Enterprise-Grade AI Marketing SaaS

ViraLoom is a premium, all-in-one AI marketing platform designed for creators, entrepreneurs, and marketing agencies. It combines the power of AI video generation, advanced SEO strategy, and viral content creation into a single, stunning glassmorphism-styled dashboard.

![ViraLoom Banner](https://v0.dev/placeholder.svg)

## 🚀 Features

### 🎥 AI Video Studio
Generate professional talking-head videos with realistic AI avatars. Simply enter your script, select an avatar, and let ViraLoom do the rest.
- Multiple professional avatars
- Voice selection (Natural, Authoritative, Energetic)
- Multi-aspect ratio support (16:9, 9:16, 1:1)

### 🔍 SEO Suite & Strategy
Dominate search rankings and social algorithms.
- **Topic Research:** Get 3 viral titles, an optimized meta-description, and 20 trending hashtags for any topic.
- **Content Calendar:** Manage your scheduled posts across all major platforms in a sleek grid view.

### ✍️ Content Lab
Generate high-converting social media captions in seconds.
- Support for Instagram, LinkedIn, and TikTok.
- Fine-tune results with **Tone** and **Target Audience** settings.

### 💳 Billing & Credits
Flexible, affordable pricing to scale with your brand.
- **Basic:** Free forever ($0)
- **Pro:** Most popular ($9/mo)
- **Unlimited:** Expert level ($25/mo)

## 🏁 Getting Started

### Prerequisites
- Node.js 18+ 
- NPM or Bun

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/viraloom.git
   cd viraloom
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env.local` file in the root directory and add your keys:
   ```bash
   OPENAI_API_KEY=your_openai_api_key
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to see the result.

## 📦 Deployment

### Deploy to Vercel
The easiest way to deploy ViraLoom is to use the [Vercel Platform](https://vercel.com/new).

1. Push your code to GitHub.
2. Import your repository into Vercel.
3. Add your Environment Variables in the Vercel dashboard.
4. Hit **Deploy**!
